# 🛒 Adverts API — REST API для сайта объявлений

Простой и удобный REST API на Flask для управления объявлениями.

## 🚀 Возможности

- ✅ Создание объявления (`POST /adverts`)
- ✅ Получение списка всех объявлений (`GET /adverts`)
- ✅ Получение одного объявления по ID (`GET /adverts/<id>`)
- ✅ Обновление объявления (`PUT /adverts/<id>`)
- ✅ Удаление объявления (`DELETE /adverts/<id>`)

## 📋 Технологии

- Python 3.7+
- Flask
- UUID для уникальной идентификации
- JSON для обмена данными
