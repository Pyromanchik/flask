# 🚀 Adverts API — Async REST API on aiohttp

Простой, быстрый и асинхронный REST API для управления объявлениями, написанный на **Python** с использованием библиотеки **aiohttp**.

## 🌟 Почему aiohttp?

- ✅ **Асинхронность**: Высокая производительность при работе с I/O (база данных, внешние API).
- ✅ **Легковесность**: Нативная поддержка asyncio в Python 3.
- ✅ **RESFull**: Полная поддержка методов GET, POST, PUT, DELETE.

## 📋 Технологии

- Python 3.7+
- aiohttp
- UUID для уникальной идентификации
- JSON для обмена данными
